# Setting: Soviet 1970s Detective

The classic Soviet crime-film mood: stoic commissars in flat caps, black-market
fartsovshchiki, khrushchevka courtyards, dim stairwells, avoska bags, podstakanniks.
Homage to the great Soviet detective films and comedies — recognizable screen types,
not real-person likenesses (master doc §4).

**Era addendum (already embedded in every prompt below):** 1970s Soviet city; boxy
suits with wide lapels, flat caps, quilted telogreika jackets, long wool coats,
floral house dresses and headscarves; props like avoska string bags, podstakannik
tea-glass holders, paper passports, black rotary phones; backdrops of khrushchevka
courtyards, snow, dim stairwell lamps, grocery shop windows.
Style core: `../_shared/style-core.md` (embedded verbatim in each prompt).

## Generation notes

- Same style core as every other setting; only era layer differs.
- Start with `_shared/contact-sheet.md` to lock the style anchor/seed.
- Keep pre-assigned accent colors when re-rolling a character.
- Optional night variant: re-light any portrait with "cold blue moonlight from one window"
  instead of the warm source; nothing else changes.
- Save results as `<basename>.png` next to their prompt files.
- After changing prompts or dropping images, run `php build.php` in `..` — it validates
  the deck and regenerates `index.json` + `gallery.html`.
