# Style-lock contact sheet (per setting)

Generate this FIRST when starting a new setting: it produces four sample heads
in one image. Pick the best quadrant as the setting's style anchor, then reuse
the same seed / style reference for every character prompt (master doc §3).
Replace `<setting description>` below with the era addendum from the folder's README.

## Prompt

Vintage gouache-and-ink game-card style reference sheet: a 2x2 grid contact
sheet of four DIFFERENT <setting description> character busts — a gruff man in
his fifties, a young woman, an elderly person, and a wiry youth — all rendered
in identical technique: waist-up busts facing the viewer, dramatic chiaroscuro
lighting from a single warm source, deep shadows, muted desaturated period
palette with exactly one saturated accent color per bust, aged textured paper
background, subtle film grain, thin double art-deco border frames around each
cell, painterly visible brushwork, no photorealism, no text, square 1:1 sheet.

## Negative

photo, photorealistic, 3d render, anime chibi, modern clothes, smartphone,
readable text, letters, numbers, watermark, logo, signature, cropped frame,
extra fingers, deformed hands, blurry, oversaturated neon colors
